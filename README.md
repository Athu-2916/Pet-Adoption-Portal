# Pet Adoption Portal

## Overview

Pet Adoption Portal is a full-stack web application designed to simplify the pet adoption process by connecting pet shelters and adopters on a single platform. Users can browse available pets, view pet details, submit adoption requests, and manage their favorite pets.

## Technologies Used

### Frontend

* React.js
* Bootstrap
* Axios
* React Router

### Backend

* Spring Boot
* Spring Security
* JWT Authentication
* REST APIs
* Hibernate/JPA

### Database

* Oracle Database

## Features

### User Module

* User Registration
* User Login Authentication
* Browse Available Pets
* View Pet Details
* Add Pets to Favorites
* Submit Adoption Requests
* Track Adoption Status

### Admin Module

* Admin Login
* Add New Pets
* Update Pet Information
* Delete Pets
* Manage Adoption Requests
* View Analytics Dashboard

## Project Architecture

Frontend (React)
↓
REST APIs (Spring Boot)
↓
Oracle Database

## Installation

### Clone Repository

git clone https://github.com/janhavimahjn/Pet-Adoption-Portal.git

### Frontend Setup

cd pet-frontend

npm install

npm start

### Backend Setup

cd pet-backend

mvn spring-boot:run

### Database Configuration

Configure Oracle Database credentials in:

src/main/resources/application.properties
